C7PL KALI PUJA & DIWALI 2026 WEB APP

HOW TO USE
1. Extract this ZIP file.
2. Open index.html in Chrome to preview.
3. To publish on Netlify: go to https://app.netlify.com/drop and drag the extracted folder (the folder containing index.html and assets) onto the page.
4. Keep the assets folder together with index.html.

Features:
- Live countdown to 8 November 2026 (India time)
- Original team photo without added watermark
- Bengali festival greeting
- Share greeting
- Diya tapping mini-game and festival quiz
- Responsive mobile design

To change the countdown date, edit the target date in index.html:
2026-11-08T00:00:00+05:30
